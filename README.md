# Aerospace Group Design Project

Group 14, Aerospace Group Design Project (UFMFUU-15-3), UWE Bristol (2023). A team of 9 took an aircraft from requirements through conceptual design: sizing, aerodynamics, structures, propulsion, stability and control, systems and cost.

## Files
| File | Description |
|---|---|
| `report/Final_Group_Design_Report.pdf` | Final group design report |
| `matlab/PrelimWeightCalc.mlx` | Preliminary sizing: L/D estimate, weight build up, wing sizing and fuel |
| `matlab/Tail_Initial_Sizing.mlx` | Tail sizing from tail volume coefficients |
| `notes/Tail_Choice.docx` | Trade study of T tail, V tail and cruciform tail options |
